# Патчи хоста DeepSeek Harness

BrainAgent работает поверх штатных хуков dsh без правки ядра, но один
дефект хоста — спам автономных гол-раундов — исправить из плагина
невозможно. Здесь лежит единственный необходимый патч хоста.

## Когда применять

После каждого обновления самого DeepSeek Harness (свежий архив/репо):

```sh
node brainagent/host-patches/apply-goal-round-pacing.cjs [путь-к-dsh]
```

Без аргумента корень dsh определяется автоматически (родительский
каталог репозитория brainagent). Скрипт **идемпотентен**: если патч уже
применён, он ничего не меняет. Если файл хоста изменился и якорь не
находится, скрипт останавливается с ошибкой и ничего не портит.

## goal-round-driver: пейсинг автономных раундов (v0.9.5)

До патча `packages/goal/goal-round-driver` допускал следующий автономный
раунд сразу при каждом переходе агента в idle — цель-напоминание
порождала четыре раунда за минуту (боевой тест 25.08.2026). Патч
допускает раунд только после непрерывного idle агента
≥ `DSH_GOAL_ROUND_MIN_IDLE_MS` (по умолчанию 180000 мс = 3 минуты,
`0` = прежнее поведение).

Затрагиваемые файлы:

- `packages/goal/goal-round-driver/src/index.ts`
- `packages/goal/goal-round-driver/tests/goal-round-driver.spec.ts`

Проверка после применения (из корня dsh):

```sh
node node_modules/vitest/vitest.mjs run packages/goal/goal-round-driver/tests/goal-round-driver.spec.ts
```

Ожидается 50/50, включая тест `goal-round pacing`.
